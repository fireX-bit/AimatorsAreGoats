Why OpenMotion

Built for beginners. Powerful for everyone.

No cloud dependency, no hidden costs, no learning curve that requires a degree. Everything you need to make motion — nothing you don't.

Text to motion

Describe the animation in plain English. OpenMotion generates keyframes and interpolates them into smooth 2D motion.

Export anywhere

Open format

Project files are plain JSON. Read them, edit them, version control them. Nothing locked behind a vendor.

How it works

Three steps. No tutorial required.

STEP 01

Describe or draw

Type a prompt like "a ball bouncing across the screen" — or drop a rough sketch and let OpenMotion trace it.

STEP 02

Preview instantly

The generated keyframes render in real time. Tweak timing, easing, and curves with sliders that actually make sense.

STEP 03

Export and go

One click renders your animation to MP4, GIF, or a sprite sheet. Or save the project file and share it.

// Inverse-kinematic chain used for the scorpion cursor trail.
// Same algorithm shown in the OpenMotion editor's "creature" plugin API.

class LimbSystem {
  constructor(end, length, speed, creature) {
    this.creature = creature;
    this.nodes = [];
    var node = end;
    for (var i = 0; i < length; i++) {
      this.nodes.unshift(node);
      node = node.parent;
      if (!node.isSegment) {
        this.length = i + 1;
        break;
      }
    }
    this.hip = this.nodes[0].parent;
  }

  moveTo(x, y) {
    this.nodes[0].updateRelative(true, true);
    var dist = Math.hypot(x - this.end.x, y - this.end.y);
    var len = Math.max(0, dist - this.speed);
    for (var i = this.nodes.length - 1; i >= 0; i--) {
      var node = this.nodes[i];
      var ang = Math.atan2(node.y - y, node.x - x);
      node.x = x + len * Math.cos(ang);
      node.y = y + len * Math.sin(ang);
      x = node.x; y = node.y; len = node.size;
    }
  }
}
Questions

Answers, no fluff.

Is it really free?

Yes. MIT license means you can use it commercially, modify it, redistribute it — anything. There's no premium tier, no feature gating, no account required.

Is it safe to install?

Every release is built from source in a public CI pipeline. You can verify the build hash or compile it yourself from the repository. The installer is signed and contains no network calls.

Does it need a GPU?

No. It runs on CPU. If you have a CUDA or Metal GPU, it'll use it automatically for faster generation, but it's not required.

When are macOS and Linux coming?

Both are actively in progress. The codebase already compiles on both — we're working on native packaging. Follow the repository to get notified when they land.

What file formats can I export?

MP4 (H.264), WebM, animated GIF, PNG sequence, and sprite sheets. You can also export the project itself as JSON to version-control or share.

Can I contribute?

Absolutely. The GitHub repository has a good-first-issue label for people new to the codebase. Documentation, translations, and bug reports are all welcome.

Where does my data go?

Nowhere. OpenMotion makes zero network requests after installation. No analytics, no crash reports, no phoning home. Everything is local.
